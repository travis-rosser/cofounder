# Implementation plans

Plans that do not belong to a single feature spec: migrations, refactors, upgrades, and
multi-feature efforts. A plan for one feature goes next to its spec in `docs/specs/` as
`-plan.md` instead.

Naming: `YYYY-MM-DD-short-description.md`. Start from `../specs/PLAN-TEMPLATE.md`.

Optional. If the project never needs a cross-cutting plan, delete this folder.
